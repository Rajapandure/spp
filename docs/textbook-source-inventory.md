# Scholars Point textbook source inventory

Target curriculum: 2026–27, Classes 1–10, English and Hindi, NCERT/CBSE and Madhya Pradesh State Board.

This file is a source register, not a claim that the PDFs have been downloaded or imported. A book is considered imported only after the original file has been obtained, its title/class/subject/medium/edition verified, and its pages extracted and checked.

## Import and extraction rules

1. Keep NCERT, CBSE and MP Board editions separate. Never map a book by subject name alone.
2. Required identity fields: academic session, board, class, subject, medium, book title, publisher, edition/year, official source URL, license/terms URL, retrieval date and file checksum.
3. Preserve the source book's chapter order, section headings, examples, exercise numbering, tables, diagrams references, formulas and page numbers.
4. Keep English and Hindi as separate source records. Do not machine-translate one edition to stand in for the other.
5. Extract textbook questions only from the matching book and chapter. Do not generate filler questions and label them as textbook exercises.
6. Store original page images/PDFs separately from extracted structured text so OCR can be audited.
7. Record extraction confidence and manually review mathematical notation, Hindi OCR, tables and multi-column pages.
8. Do not bundle or republish a source PDF in the app until its license clearly permits that use. NCERT's textbook portal currently warns against use of its online books as part of third-party digital content packages/software; its separate e-content license has non-commercial distribution conditions. Treat this as a rights check, not blanket permission.
